# Movie Data Analytics Project

This portfolio project explores a movie dataset using Excel, with data cleaning, summary tables, and visualizations.

## Project workbook
- `Movies_Data_Analytics_Project.xlsx` — cleaned dataset, analysis tables, summaries, data-quality checks, and charts.

## Tools
- Microsoft Excel / Google Sheets

## Analysis questions
1. Which movies have the highest recorded revenue?
2. Which highly rated movies have a meaningful number of votes?
3. Which original languages occur most frequently?
4. How does the number of movies vary by release year?
5. What data-quality issues should be considered before drawing conclusions?

## Data notes
- Duplicate rows were removed in the cleaned data.
- Missing runtime values are left blank rather than guessed.
- Zero budgets may mean unreported values and should be interpreted cautiously.
- Revenue is not the same as profit because other costs are not included.

## How to use
Open the workbook and review its summary, cleaned data, analysis tables, and charts. Add a few evidence-based findings before presenting this project on a resume.
